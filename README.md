# TOP-Calculator

A simple calculator built with **HTML, CSS, and JavaScript** as part of **The Odin Project – Foundations**.

This project does not use `eval()` and handles all calculations through explicit logic and state management.

---

## Features

- Basic operations: **Addition, Subtraction, Multiplication, Division**
- Chained calculations (e.g. `12 + 7 - 1 =`)
- Operator displayed on the screen
- Decimal number support
- Percentage conversion
- Clear and delete (backspace) functions
- Responsive layout using CSS Grid

---

## Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla)

---

## What I Learned

- Managing application state in JavaScript
- Handling user input with event listeners
- Avoiding `eval()` and implementing custom calculation logic
- Dealing with floating-point precision issues
- Structuring reusable and maintainable CSS
